# This is the overview page of the GitHub organization for the Theory, ApplicatioN and DEvelopment of nuMerical algorithMs Laboratory (TANDEMM-Lab)

The group's objective is combining Numerical Linear Algebra, Deep Learning, and Statistical and Theoretical Physics, all under the light of Neuromorphic Computing, in order to help in reducing the heavy energetic consumption currently ailing the booming use of AI, while gaining a deeper understanding of brain-inspired algorithms and their connection with physical systems.
